⏰ Reminders until you read

An iPhone web app can't send notifications by itself, so Lamp uses Apple's free Shortcuts app. Your iPhone checks several times a day and only reminds you if you haven't tapped Stop today's reminders yet. Set it up once (about 10 minutes):

Show setup steps

A. Shortcut “Lamp Done”

  1. Open Shortcuts → tap +. Name it exactly Lamp Done.
  2. Add action Format Date. Set Date to Current Date, Date Format Custom, format yyyy-MM-dd.
  3. Add action Save File. Turn Ask Where to Save off. Set Subpath to lamp-done.txt and turn Overwrite If File Exists on.
  4. Add action Show Notification: Streak secured ✅ No more reminders today. Tap Done.
  5. Optional: long-press it → Share → Add to Home Screen.

B. Shortcut “Lamp Check”

  1. New shortcut named Lamp Check.
  2. Add Get File from Folder: Folder Shortcuts, File Path lamp-done.txt, and turn Error If Not Found off.
  3. Add Get Text from Input (input: the File).
  4. Add Format Date: Current Date, Custom, yyyy-MM-dd.
  5. Add If: Text does not contain Formatted Date.
  6. Inside the If, add Show Notification: 📖 Your Bible is waiting — keep your 🔥 streak alive!

C. Automations (the repeating reminders)

  1. Shortcuts → Automation tab → + → Time of Day.
  2. Pick 7:00 AM, Daily, choose Run Immediately, then select Lamp Check.
  3. Repeat for 10 AM, 1 PM, 4 PM, 7 PM and 9 PM (or any times you like).
  4. Test it: run Lamp Check now and you should get a reminder. Run Lamp Done, then run Lamp Check again. You shouldn't get one.
